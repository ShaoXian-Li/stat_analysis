把毕业生就业数据（Excel）一键转换成**带图表、带目录的 Word 分析报告**，无需任何命令行操作。

本项目面向高校院系就业统计工作，包含两个可以独立使用的程序：

| 程序 | 源文件 | 用途 | 输入 | 输出 |
| --- | --- | --- | --- | --- |
| **就业质量报告生成器** | [`report_generator.py`](report_generator.py) | 单个年度的就业质量报告 | 1 份年度就业数据 xlsx | `xxx.docx` + `image/` 图表 |
| **就业变化趋势分析器** | [`trend_analyzer.py`](trend_analyzer.py) | 多个年度的就业趋势分析 | 多份按年份命名的 xlsx | `毕业生就业趋势分析报告.docx` + `image_trends/` 图表 |

两个程序均为图形界面（弹窗选择文件），也可以打包成单个 `.exe` 直接分发，接收方无需安装 Python。

---

## 功能特性

- **零命令行**：运行后依次弹窗选择数据文件、保存位置和报告标题，全程无需记参数。
- **自动化排版**：自动生成 Word 目录（域）、三线表、图表与文字说明，图表统一使用中文字体。
- **统计口径明确**：升学 / 境外升学、落实 / 未落实、稳定工作、科研单位、科研倾向、教育行业倾向等口径全部写在代码与说明书中，可追溯到具体判定规则。
- **卡方检验**：对"是否回乡"与"是否选择稳定工作"做卡方检验，输出 P 值与显著性结论。
- **多维度可视化**：堆叠柱状图、分组柱状图、饼图、生源地 × 就业地网格热力图、中国地图热力图（可选）、趋势折线图。
- **一键打包**：内置 PyInstaller 配置与 `build.ps1`，一条命令产出两个 exe。

## 快速开始

### 方式一：直接使用打包好的 exe

在仓库的 [Releases](../../releases) 页面下载 `就业质量报告生成器.exe` 与 `就业变化趋势分析器.exe`，双击即可运行，无需安装 Python。

> 体积约 200 MB 属于正常现象（单文件模式已内嵌 Python 解释器、pandas、matplotlib 等）。

操作步骤、数据格式要求与统计口径见 [使用说明.docx](使用说明.docx)（Word 版，含表头要求与常见问题）。

### 方式二：从源码运行

```powershell
git clone https://github.com/ShaoXian-Li/stat_analysis.git
cd stat_analysis

python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

python report_generator.py    # 就业质量报告生成器
python trend_analyzer.py      # 就业变化趋势分析器
```

## 数据要求

数据必须是 **xlsx** 格式，且**首行为表头**。列名支持包含匹配（例如程序会同时接受 `毕业生去向` 与 `毕业去向`）。

### 就业质量报告生成器

| 列名 | 必需 | 说明 |
| --- | --- | --- |
| 学历 | ✅ | 内容需含"本 / 硕 / 博"字样，用于区分本、硕、博 |
| 层次 | 建议 | 当"学历"列无法识别时作为兜底 |
| 培养方式 | ✅ | 需含"定向 / 非定向"；**后续就业结构分析仅统计非定向生** |
| 生源所在地 | ✅ | 取前 2 个汉字作为省份（如"河北石家庄"→"河北"） |
| 毕业生去向 | ✅ | 用于落实率、升学判定、剔除升学人员 |
| 单位性质 | ✅ | 用于稳定工作、科研单位、教育行业判定 |
| 单位所在地 | ✅ | 用于就业地分布、地图、核心经济区统计 |
| 单位名称 | ✅ | 用于升学单位、就业单位统计 |
| 师范生类别 | 建议 | 用于识别公费师范生 |
| 工作职位类别 | 可选 | 当前版本未参与统计，保留以兼容原始表格 |
| 定向或委培单位 | 可选 | 当前版本未参与统计，保留以兼容原始表格 |

缺少必需列时，程序会弹出明确的提示，指出缺了哪一列，而不是抛出看不懂的 KeyError。

### 就业变化趋势分析器

| 列名 | 必需 | 说明 |
| --- | --- | --- |
| 学历 | ✅ | 内容需含"本 / 硕 / 博"；硕士含"学术"或"专业"时会进一步细分 |
| 毕业生去向 | ✅ | 用于升学 / 就业 / 科研助理 / 拟升学等判定 |
| 单位性质 | ✅ | 用于科研单位、企业等判定 |
| 单位所在地 | ✅ | 用于省份与经济区归属 |
| 单位名称 | ✅ | 用于 985 / 211 / 其他科研单位判定 |
| 专业 | ✅ | 用于区分"应用心理（专硕）"与"心理学（学硕）" |
| 师范生类别 | 建议 | 用于在本科统计中排除公费师范生 |
| 工作职位类别 | 可选 | 当前版本未参与统计 |

**文件名必须包含 4 位年份**，例如 `2021届就业数据.xlsx`、`2022就业质量.xlsx`。年份决定趋势图的横轴，且决定年份排序；文件名不含年份的文件会被静默忽略。

## 使用流程

### 就业质量报告生成器

1. 双击 `就业质量报告生成器.exe`（或运行 `python report_generator.py`）。
2. 弹窗提示选择 **Excel 数据文件**（xlsx）。
3. 选择 **保存位置并输入文件名**，默认文件名为"心理学部 + 当前年份 + 年就业质量报告"。
4. 等待程序运行完成，完成后弹窗提示保存路径；运行出错时也会弹窗显示原因。
5. 首次打开生成的 Word 文档时，Word 会提示"**此文档包含的域可能引用了其他文件**"，点击"**是**"即可自动生成目录。

报告章节结构：

```
一、毕业生构成
    1. 毕业生学历
二、毕业生就业结构
    1. 毕业生去向落实率
    2. 升学统计
    3. 就业单位性质统计
    4. 就业单位统计
    5. 就业单位所在地（含 5.1 生源地 × 就业地网格图、5.2 核心经济区分布）
    6. 毕业生的就业偏向（6.1 科研倾向、6.2 教育行业倾向）
三、毕业生就业影响因素
    1. 是否回乡与选择"稳定工作"的偏好（含卡方检验）
```

### 就业变化趋势分析器

1. 双击 `就业变化趋势分析器.exe`（或运行 `python trend_analyzer.py`）。
2. 弹窗提示选择 **多个年度的 Excel 文件**（可多选，文件名需含年份）。
3. 选择 **保存目录**。
4. 程序按年份排序后生成趋势报告，完成后弹窗提示保存路径。

报告章节结构：

```
一、博士毕业生就业趋势
二、核心经济区流向趋势（本科 / 硕士 / 博士）
三、毕业生去向趋势（本科 / 硕士-应用心理 / 硕士-心理学 / 博士）
四、科研助理占比趋势
五、学术型硕士升学比例趋势
```

## 输出说明

- 两个程序都会在报告所在目录下创建图表文件夹：`image/`（质量报告）与 `image_trends/`（趋势分析）。
- 图表同时以 200 dpi PNG 形式保存，可直接用于 PPT 或公众号推文。
- Word 报告中的表格为可直接编辑的普通表格（三线表样式）。

## 统计口径

以下口径与代码实现一一对应，便于复核：

| 口径 | 判定规则 |
| --- | --- |
| 落实 / 未落实 | "毕业生去向"含"拟升学、待就业、不就业拟升学、暂不就业、求职中"→未落实；空值→未落实；其余→落实 |
| 国内升学 / 境外升学 | 含"境外、出国、留学"→境外升学；含"研究生、升学"→国内升学 |
| 出国 | "单位所在地"含"国外、境外、出国、留学"字样 |
| 稳定工作 | "单位性质"含机关、国有企业、部队、其他事业单位、高等教育单位、中初教育单位、医疗卫生单位、科研设计单位 |
| 科研单位 | "单位性质"含高等教育单位或科研设计单位 |
| 教育行业 | "单位性质"含中初教育单位（不含高等教育单位） |
| 核心经济区 | 京津冀（北京 / 天津 / 河北）、珠三角（广东 / 香港 / 澳门）、长三角（上海 / 江苏 / 浙江 / 安徽）、成渝（四川 / 重庆） |
| 省份归并 | "单位所在地"取前 2 个汉字；"国外 / 境外 / 出国 / 留学"统一记为"国外" |

## 打包为 exe

```powershell

# 方式一：一键打包两个程序
.\build.ps1

# 方式二：分别打包
```

## 常见问题

<details>
<summary><b>图表里的中文变成了方框</b></summary>

程序默认按 `SimHei` → `Microsoft YaHei` → `Noto Sans CJK SC` → `WenQuanYi Zen Hei` 的顺序挑选系统中可用的中文字体。若全都没有，请安装其一，或修改两个程序中 `plt.rcParams["font.sans-serif"]` 这一行。
</details>

<details>
<summary><b>Word 打开后没有目录</b></summary>

目录是 Word 的"域"，需要手动更新：打开文档时点击提示中的"是"，或在目录上右键 →"更新域"→"更新整个目录"。
</details>

<details>
<summary><b>提示缺少某列 / KeyError</b></summary>

表头与本文档"数据要求"不一致。程序会列出缺少的列名与当前全部表头。仅支持少量别名（`毕业生去向` / `毕业去向`、`生源所在地` / `生源地`、`专业` / `学科专业`），其余列名需完全一致；程序会自动去除首尾空格与全角空格。
</details>

<details>
<summary><b>报告里没有中国地图</b></summary>

地图依赖可选的 `geopandas`，且首次运行需要联网下载 GeoJSON 边界数据。未安装或下载失败时程序会自动跳过地图，其余图表正常生成。
</details>

<details>
<summary><b>"心理学部"字样需要改成我院名称</b></summary>

部分段落文字中写有"心理学部"。在 `report_generator.py` 中搜索"心理学部"并替换为所在院系名称即可；报告标题本身由你在保存时输入的文件名决定。
</details>

<details>
<summary><b>exe 为什么有 200 MB 多</b></summary>

单文件模式把 Python 解释器与 pandas、matplotlib、scipy 等依赖全部内嵌，体积大但可以脱离环境独立运行。
</details>

## 数据隐私

**请勿把真实的毕业生数据（xlsx）提交到仓库。** `.gitignore` 已默认忽略所有 `*.xlsx` 与 `data/` 目录，仅放行 `examples/` 下的模板文件；提交前请再执行 `git status` 确认一次。
